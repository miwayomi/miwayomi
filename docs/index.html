miwayomi.

A self-contained server that runs Aniyomi/Tachiyomi-format catalog extensions on the JVM — no Android, no emulator, no cloud.

Read the documentation View source
mi·wa·yo·mi — “beautiful reading”

What it is

⚙️ Execution engine

Loads extensions in the Tachiyomi/Aniyomi format and exposes their sources through a clean REST API and a web UI.

📱 No Android

A crafted shim (android-compat) makes extensions believe an Android runtime exists — on a plain JVM.

🪶 Lightweight

A single java process, ~160–170 MB RSS at rest. Comfortable on a 4 GB VPS.

🎬 Full playback

HLS, DASH and direct MP4/WebM through a chunked, memory-neutral streaming proxy.

🗄️ Persistence

Cookies, resolved Cloudflare hosts, favorites and reading progress in SQLite.

🌐 Multilingual UI

One JSON file per language — add a file to add a language.

Download

Runnable JAR — one file, any OS

Grab the latest release: a single cross-platform JAR. You only need JDK 21.

⬇ Download miwayomi (Releases)

The JAR is a snapshot of the engine — it ships no extensions or content. You install sources from the web UI.

Run it on any OS

Linux / macOS

java -jar miwayomi-all.jar --data ./data --port 4567

Windows (PowerShell / CMD)

java -jar miwayomi-all.jar --data %cd%\data --port 4567

FlareSolverr is enabled by default at http://127.0.0.1:8191. If it is not running, Cloudflare challenges fall back to the manual modal.

Open http://localhost:4567. Full build, run, and extension guides are in the documentation.
